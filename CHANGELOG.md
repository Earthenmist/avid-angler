# Changelog

## 2026-09-08 - v1.0.5-Release

### Changes

- Assign fishing shortcuts through Blizzard's Keybindings, with a link from
  Settings, two key slots and built-in conflict handling.
- Existing shortcuts migrate when free, with guidance for conflicting keys.
- Return to Avid Angler after closing the Keybindings window opened from it.

### Fixes

- Escape now closes an achievement guide without closing the main Avid window.
- Fixed fishing shortcuts becoming inactive when held during a cast.
- Removed fishing skill books and other unrelated items from lure choices.
- Extra toy slots skip reuse while a recognised matching buff is active.
- Fixed stale scores in the floating window during continuous fishing or
  with Keep open enabled.
- Improved collectible appearance checks and corrected Eerie Bauble ownership.

### Known issues

- None currently reported.
