# Changelog

## 2026-09-07 - v1.0.2-Release

### Changes

- Added fishing achievement pages for every expansion, with live progress,
  completion states and compact two-column cards.
- Added completion guides with practical advice and waypoint buttons for
  TomTom or Blizzard's map.
- Grouped achievement chains around the next unfinished step, with all steps
  shown in the guide.
- Left-click for a guide, right-click to open Blizzard's achievement window,
  or Shift + right-click to toggle tracking. Tooltips explain each action.
- Added remembered filters for completed achievements and Midnight's Abyss
  Anglers achievements, which are hidden by default.
- Included optional historical achievements and faction-aware lists, with
  Classic and Burning Crusade objectives grouped by their content.
- Localized achievement controls, guides and waypoint labels across all
  supported languages, with Blizzard-backed game names where available.

### Fixes

- Excluded recipes and Bloom Bauble from automatic fishing-action selections.
- Separated lure and ward selections so one of each can be kept active,
  with remembered choices and independent buff checks.
- Corrected eight Classic fish using cooked item IDs, restoring their raw
  catches to fish totals in both new catches and saved history.
- Fixed broken German characters and number formatting.

### Known issues

- None currently reported.
