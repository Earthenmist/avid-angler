# Changelog

## 2026-09-08 - v1.0.6-Release

### Changes

- Bundled LibDBIcon for better compatibility with minimap button bags and bars.
- Added a saved UI scale control in Settings and the addon version beside its heading.
- Added dismissible warnings when a selected lure or ward expires with none left in your bags.

### Fixes

- Minimap button now follows the outside edge of round and square minimaps,
  including resized ElvUI maps, and drags correctly with minimap scaling.

### Known issues

- Blizzard's Interact key can miss bobbers when fishing from ledges; click the bobber directly if this occurs.
