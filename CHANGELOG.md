# 1.2.0-Release

## Changes
- Added WoW Forever support. On Forever, Avid Angler shows only Classic content, reads the single Fishing skill, and hides Scoring, achievements, Midnight features and the Venom alert. Retail is unchanged.
- Forever has its own fishing data: trainers (including Zephras Isle and Riverglades), fish such as Whimsyfin, pools, lures, fishing gear and the Bitter Baitling pet.

## Fixes
- Audio Focus volume changes now save. Before, a value typed into one box reset to the saved value when you moved to another box, so Save kept the old volumes.

## Known issues
- Some Forever trainer positions and fish sources are not yet confirmed in game.
